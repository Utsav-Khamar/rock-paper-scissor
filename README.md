# Rock Paper Scissors

A Rock Paper Scissors game built as part of The Odin Project.

This repository contains:

- A browser-based JavaScript version with an interactive user interface
- A Python version

## Live Preview

https://utsav-khamar.github.io/rock-paper-scissor/

## Features

- Interactive Rock, Paper, and Scissors buttons
- Random computer move generation
- Displays player and computer moves
- Real-time score tracking
- Round-by-round result messages
- First player to reach 5 points wins
- Disables game buttons when the game ends
- Displays a winner message
- Restart button to start a new game
- Responsive layout using CSS Flexbox

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
